# docs/lessons.md — 深度理由与踩坑史（按需加载）

本文件记录"为什么这么做"和已证伪的路线，避免重试。根 `AGENTS.md` 只保留可执行规则，工程细节与历史放这里，需要时再读。

## 1. LaMa/MAT"见字生字"机制（字形复活）
- 现象：笔画级 mask 若字符间隙未被覆盖，间隙里残留的水印字形轮廓（描边/字符边界）会被模型（LaMa 的 FFT 全局感受野）捕捉，按"字形延续"填充每个笔画洞 → 文字形状复活（4.png 小膨胀时"豆"字复活、6.png 3px 膨胀时整行文字回归）。
- 历史破解（旧二值 mask 时代）：水平膨胀到字符间距填满（±9px）使 mask 连片、垂直 ±5px（19x11 核）盖抗锯齿。**该配方已废弃**，被连续 α mask 取代（见 §2）。
- 位置对齐比膨胀参数更关键：mask 放置偏 8px 时小膨胀盖不住字形，会误判为"垂直膨胀不足"（6.png 扁核曾因放在旧位置 (2538,1498) 残留，正确位置 (2541,1490) 下 ±3px 即可）。

## 2. 连续 α mask（当前方案，取代二值+大膨胀）
- 豆包水印是"半透明白字 + 暗色描边"（stamp 逐像素颜色 C：填充区≈255、边缘低至≈64），sRGB 线性混合：obs = α·C + (1−α)·bg。
- 用黑底 2.png 提取连续 α 图 `tools/doubao-wm-alpha.png`；mask = α>0.03 的污染像素 + 1px 缓冲。α 图已完整覆盖抗锯齿带，字符间隙无字形上下文，**3x3(±1px) 即够**，MAT/LaMa 均无字形复活。
- 旧二值模板（α>0.5）只盖笔画核心，须靠 7x7/19x11 大膨胀补抗锯齿，属过度覆盖——正是"去掉水印后周边元素被动过"的根因。连续 α 比旧方案少重绘 ~10–30%。
- **模板匹配用顶帽 gap-score**：亮背景（纸面/花墙/雪）会压低"笔画−间隙"绝对差，使 3.png 纸面低对比水印漏判（raw max(RGB) gap 仅 15，低于已去水印负样本）。改为先做 31x31 椭圆开运算顶帽扣除局部背景，再做两次 `cv2.matchTemplate`（0/1 模板核取 S_in、全 1 核取窗口和，gap = S_in/N_in − S_out/N_out），判据与背景亮度无关。实测：2.png 145 / 5.png 136 / 4.png 96 / 1.png 59 / 6.png 53 / 3.png 33；已去水印负样本 ≤8.4；阈值取 20（中间空档）。

## 3. TELEA 粗填已废弃（重要，勿重试）
- 早期认为"粗填（TELEA 插值）把 mask 区填成背景延续、消除字形信息，因此 MAT+粗填可把 mask 缩到 ±3px"。
- **已证伪**：iopaint 推理时会把 mask 区 source 像素置零（MAT/LaMa 受控实验输出逐像素相同，2026-09 确证），任何粗填/预处理都无法影响模型输入。历史"粗填有效"结论系旧环境误导。管线里的 TELEA 粗填已作为死代码移除，`inpaint` 现在无粗填、直接推理。
- 结论：修复质量完全由 mask 外的上下文决定，mask 精度是唯一杠杆。

## 4. stamp 逆解（`--inverse`，Python 默认开启、逐图自动择优）
- 单层白字公式 `bg=(obs−255α)/(1−α)` 已证伪，根因是水印模型不完整（漏了暗色描边）。正确模型为完整 stamp `obs = α·C + (1−α)·bg`；用多张同款水印、不同背景的参考图联立标定 α 与 C（资产 `tools/doubao-wm-stamp.npz`），逐像素反解恢复被覆盖的**真实背景**（非生成）。
- gating（不满足则保持 MAT）：模板命中 + scale≈1.0 + 水印邻域纹理复杂（HF≥9）+ 逐图 α 增益自校正（最小化残影与 α 相关性）+ 饱和像素回退。
- 常量：`STAMP_REF_SHORT=1600`、`INVERSE_SCALE_TOL=0.03`、`INVERSE_TEXTURE_MIN=9.0`、`INVERSE_ALPHA_GAIN_RANGE=(0.8,1.25)`、`INVERSE_MAX_GHOST=0.12`。
- 效果：6.png 花丛类明显优于 MAT；低纹理（暗底/沙面/纸面）与缩放图（4/5，stamp 非简单缩放）仍走 MAT。
- **越界修复**：逆解只改写"声明的 mask"内（stamp α 比模板 mask 略宽，放任越界会破坏"mask 外零改动"硬性保证）。曾因此发现越界 bug（12572px vs 10172px）。
- **回退策略**：只在【模型失解】（逆解 raw 超出 [0,255]，obs 无法由 α·C+(1−α)·bg 解释）或全通道饱和时回退 MAT。旧的"任一通道饱和即回退 MAT"会让 MAT 在亮背景饱和像素上凭空生成深色斑点（6.png 实测原图 239→MAT 37 的黑点 artifact）；改为仅失解回退后消失、模板残留不变（10.1→10.2）。
- 不可逆地板：obs 饱和像素（6.png 占 mask 12~16%）与高 α 核心的噪声放大 1/(1−α)。

## 5. 已证伪/勿重试清单
- **mask 边缘羽化混合**：mask 外残留的水印抗锯齿像素会被羽化权重混回，字形半透明浮现——mask 精确覆盖时任何"往回混"的操作都带回水印。
- **单层白字反解公式**：见 §4。
- **`--refine` 框内笔画精分割自检**：纸面纹理（3.png 90% 漏检）、复杂花丛+低对比水印（6.png 误检+漏检）、黑底暗侧误检，四种自检判据（面积占比/组件数/多假设 IoU/粗填-复检收敛性）均无可靠区分度——无先验、无参考的笔画分割自检是信息论限制，勿继续投入。
- **crop margin 调到 256**：会让 MAT 在"成"字区生成暗色伪影块，维持默认 128（64/128 实测持平）。
- **pad 反射**：见 desktop/AGENTS.md（会镜像水印进上下文）。
- **宽泛启发式兜底**：如"任一通道饱和→用另一模型"本身会注入伪影。宁可只在明确的模型失解条件下回退，也不要用宽泛启发式触发。

## 8. 事故：`--root dist`
曾误用 `--root dist` 执行 overwrite-review + cleanup，把处理结果覆盖进 dist/ 原图目录且备份被清理，原图丢失（用户手动恢复）。规则：`--root` 始终是"被处理文件所在的输出目录"；本项目 `dist/` 是只读原图源，任何写操作（overwrite-review/cleanup/run）的 `--root` 都不得指向 `dist/`。为此 prepare 记录源文件 md5 到 `WORK/manifest.json`，overwrite-review 覆盖前校验，不一致即拒绝。

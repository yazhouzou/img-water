# docs/lessons.md — 深度理由与踩坑史（按需加载）

记录"为什么这么做"与已证伪路线，避免重试。根 `AGENTS.md` 只留可执行规则。

## 1. LaMa/MAT"见字生字"（字形复活）
- 笔画级 mask 若字符间隙未覆盖，间隙残留的水印字形轮廓被模型（LaMa FFT 全局感受野）捕捉，按字形延续填洞 → 文字复活（4.png 小膨胀"豆"复活、6.png 3px 膨胀整行回归）。
- 旧二值 mask 破解：水平膨胀到字符间距填满（±9px）连片、垂直 ±5px（19x11 核）盖抗锯齿；**已废弃**，被连续 α mask 取代（§2）。
- 位置对齐比膨胀参数更关键：偏移 8px 时小膨胀盖不住字形（6.png 旧位置 (2538,1498) 残留，正确 (2541,1490) 下 ±3px 即可）。

## 2. 连续 α mask（当前方案）
- 豆包水印=半透明白字+暗色描边（stamp 逐像素 C：填充≈255、边缘低至≈64），sRGB 线性混合 `obs=α·C+(1−α)·bg`。
- 黑底 2.png 提连续 α 图 `tools/doubao-wm-alpha.png`；mask=α>0.03 污染像素 +1px 缓冲。α 已覆盖抗锯齿带、字符间隙无字形上下文，**3x3(±1px) 即够**，MAT/LaMa 均无复活。
- 旧二值模板（α>0.5）只盖核心，须靠 7x7/19x11 大膨胀补抗锯齿 → 过度覆盖（"周边被动过"根因）。连续 α 少重绘 ~10–30%。
- **模板匹配用顶帽 gap-score**：亮背景（纸面/花墙/雪）会压低"笔画−间隙"绝对差致 3.png 漏判（raw max(RGB) gap 仅 15）。改为 31x31 椭圆开运算顶帽扣局部背景，再两次 `cv2.matchTemplate`（0/1 核取 S_in、全 1 核取窗口和，gap=S_in/N_in−S_out/N_out），判据与亮度无关。实测 2.png 145/5.png 136/4.png 96/1.png 59/6.png 53/3.png 33；已去水印负样本 ≤8.4；阈值 20（中间空档）。

## 3. TELEA 粗填已废弃（勿重试）
- 曾认为"粗填（TELEA）把 mask 区填成背景延续、消除字形信息，故可把 mask 缩到 ±3px"。
- **已证伪**：iopaint 推理会把 mask 区 source 置零（MAT/LaMa 受控实验逐像素相同，2026-09），任何粗填都无法影响模型输入；"粗填有效"系旧环境误导。管线 TELEA 已作死代码移除。
- 结论：修复质量由 mask 外上下文决定，mask 精度是唯一杠杆。

## 4. stamp 逆解（`--inverse`，Python 默认开、逐图择优）
- 单层白字公式 `bg=(obs−255α)/(1−α)` 已证伪（漏暗色描边）。正确模型为完整 stamp `obs=α·C+(1−α)·bg`；用多张同款水印不同背景参考图联立标定 α、C（资产 `tools/doubao-wm-stamp.npz`），逐像素反解恢复**真实背景**（非生成）。
- gating（不满足保持 MAT）：模板命中 + scale≈1.0 + 邻域纹理复杂（HF≥9）+ α 增益自校正 + 饱和像素回退。
- 常量：`STAMP_REF_SHORT=1600`、`INVERSE_SCALE_TOL=0.03`、`INVERSE_TEXTURE_MIN=9.0`、`INVERSE_ALPHA_GAIN_RANGE=(0.8,1.25)`、`INVERSE_MAX_GHOST=0.12`。
- 效果：6.png 花丛优于 MAT；低纹理（暗底/沙面/纸面）与缩放图（4/5）仍走 MAT。
- **越界修复**：逆解只改写声明的 mask 内（stamp α 比模板 mask 略宽；曾越界 bug 12572px vs 10172px）。
- **回退**：只在【模型失解】（raw 超 [0,255]）或全通道饱和时回退 MAT。旧"任一通道饱和即回退"会让 MAT 在亮背景饱和像素生成深色斑点（6.png 原图 239→MAT 37 artifact）；改后消失、模板残留不变（10.1→10.2）。
- 不可逆地板：饱和像素（6.png 占 mask 12~16%）与高 α 核心噪声放大 1/(1−α)。

## 5. 已证伪/勿重试
- **mask 边缘羽化混合**：mask 外的抗锯齿像素被羽化权重混回 → 字形半透明浮现。
- **单层白字反解公式**：见 §4。
- **`--refine` 框内笔画精分割自检**：纸面（3.png 90% 漏检）、花丛+低对比（6.png 误漏检）、黑底暗侧误检，四种判据（面积占比/组件数/多假设 IoU/粗填-复检收敛）均无区分度——无先验/参考的笔画自检是信息论限制，勿投入。
- **crop margin 调 256**：MAT 会在"成"字区生成暗色伪影块；维持 128（64/128 持平）。
- **pad 反射**：见 §11（镜像水印进上下文）。
- **宽泛启发式兜底**（如"任一通道饱和→换模型"）本身注入伪影；只在明确模型失解时回退。

## 8. 事故：`--root dist`
曾误用 `--root dist` 做 overwrite-review + cleanup，把结果覆盖进 dist/ 原图且备份被清理，原图丢失（用户手动恢复）。规则：`--root` 始终是"被处理文件所在输出目录"；本项目 `dist/` 只读，任何写操作（overwrite-review/cleanup/run）的 `--root` 都不得指向它。为此 prepare 记源 md5 到 `WORK/manifest.json`，overwrite-review 覆盖前校验，不一致即拒。

## 9. 修复方法论（普适原则）
1. **mask 最小化第一**：只覆盖真正被破坏的像素（核心 + 抗锯齿 ±1–3px），膨胀从最小试。
2. **先消除字形泄漏**：mask 盖住边缘即可（iopaint 把 mask 区 source 置零）；用连续 α mask，勿回退二值+大膨胀。
3. **模型匹配复杂度**：均匀背景 LaMa 够；复杂结构（花丛/棱线/阴影）必须 MAT。
4. **量化优先于目检**：changed/lost/gain + "mask 外零变化"断言；已固化 `verify_paths`。
5. **接受信息论极限**：被笔画压住的像素不可逆，差异属极限勿调参，唯一杠杆是 mask 精度；像素级还原走 `--inverse`。

## 10. 检测范围与跳过策略（勿扩大修复面）
- **检测参数**：全图白字用阈值 248→150 融合；顶帽 31x31 低饱和 + 文字性验证；框过**字符行判据**（高度统一、行内 ≥4 字、高度比 ≤1.8）；膨胀只允许 5x5 一次。模板按短边缩放，右下 40px 窗口 gap-score ≥20 命中，命中写连续 α 笔画 mask（α>0.03+1px）并写 `.tpl`；不足回退整框，再不到则空 mask 跳过。
- **只留贴右下角**：豆包水印必贴右下；雪景白点/白墙/栏杆/纸面高光会被"全图白字"判据误检，硬修毁图。非 `--any-position` 时只保留 `x2 > W-40 && y2 > H-40` 的框，分散水印改走 `--mask-box`。
- **检不到即跳过**：空 mask 绝不进模型——对已无水印的图硬修会把真实画面重绘成模糊块，宁可不改。防御：全部无 mask 透传时 source 为空，必须跳过 iopaint（空目录报 `invalid --image` 退出 255）。
- **模板命中即完成**：默认模式命中模板笔画 mask 后直接产出，不再叠加整框检测；`--any-position` 才把模板与其它位置检测叠加（并丢弃与模板重叠的 DBNet 框，避免重复修复）。

## 11. Rust 内核演进（勿回退）
- **tile → crop**：v0.3.9 用 512 tile，每块只看到半截水印 → 接缝/模糊（App 端模糊根因之一）；v0.5.1 改对齐 iopaint CROP（每遮罩连通块 bbox+128px，crop ≤512 原分辨率居中 pad、更大等比缩到 512 推理后 Lanczos 还原）。
- **pad 禁反射**：v0.5.3 起 pad 必须用图像均值色常数填充。反射 pad 会把贴边水印镜像进上下文 → 残影（水印贴图底时 mask 必贴 crop 边，此坑必现）。
- **"App 影响周边元素"根因（v0.5.5）**：模型只写回 mask 内像素（`lama.rs` 只在 `crop_mask>0` 处写回），所以"周边被改动"100% 是 **mask 盖住了不该动的像素**，不是模型越界。旧 Rust 模板 mask 抄了「二值核(>127) + 19x11 膨胀」——但 19/11 在 Python 里是 `REFINE_DILATE_LAMA`（给"框内精分割失败后退化整框"用的），被错用到最该精细的模板笔画路径上 → 靠大膨胀补抗锯齿，多盖 ~38% 干净画面（实测 16419px → 10172px，dist/1）。叠加第二重放大：无顶帽 + 阈值 40（Python 20）使亮背景分数跌破阈值 → 回退整框 mask（无 refine），面积再涨 3~5 倍。修法：embed `tools/doubao-wm-alpha.png` 取 α>0.03 作核 + 1px 膨胀（对齐 Python `TEMPLATE_STROKE_DILATE`），gap-score 先扣 31x31 椭圆顶帽、阈值降 20。修复后 Rust mask 与 Python 逐像素一致（IoU=1.0000）。
- **顶帽只算搜索窗**：模板搜索窗仅右下角 41x41 个位置，故顶帽只需在「窗 + 核半径」范围计算（`ellipse_morph` 用逐行一维滑窗，O(r·n)）；全图朴素 31x31 形态学是 O(n·k²)，必须避免。
- **ghost 度量必须用「有符号跨通道 max」**：Python 的两处逆解都是 `(inv − blur).max(axis=2)`，Rust 曾误写成先 `abs` 再 max → 残影与 α 的相关方向被改，增益选偏（6.png 选到 1.00，Python 选 1.05），水印区双端 MAD 1.85/P95=16；改回有符号后增益一致、MAD 0.46/P95=2。此函数档案库与 stamp 共用，两边都受益。
- **cv2 椭圆核公式（v0.5.5 精分割一致性根因）**：`getStructuringElement(MORPH_ELLIPSE,(2r+1)²)` 的每行半宽是 `cvRound(r·√(1−(dy/r)²))`，**不是** `floor(√((r+0.5)²−dy²))`——两者只在最外几行差 1~3px（dy=±14 时 5 vs 6、dy=±15 时 0 vs 3），但顶帽/开运算的边缘像素随之漂移，细纹理图（3.png 纸面）会因此多/少检出一大批笔画（3.png 甚至从"整框退回"变成有效精分割）。改成 cv2 公式后，模板 mask 与 `refine_box_mask` 双双 IoU=1.0000（dist/1、2、3、6）。
- **`boxFilter` 默认 BORDER_REFLECT_101 + 偶数核锚点**：`ksize=96` 时窗口是 `[x−48, x+47]`（96 项，非对称），边界用 reflect-101 外推；Rust 曾用"积分图 + 越界截断 97 项"，边缘 std 偏差 → 阈值翻转。精分割内的局部自适应阈值必须按此实现。
- **精分割别写 `.tpl`（假残留陷阱）**：`.tpl` 在 Python/Rust 里都被当成"本轮确实命中豆包模板"的强证据，会强制启用模板残留检查。框选精分割对**任意**水印都生效（千问/3DMGAME…），若也写 `.tpl`，非豆包图（7.png scale=1.1）的模板分 33.8 就被当成残留 → 假 FAIL → 无谓退化整框。改法：精分割只写 `.refinebox`，`verify_paths(template_applied: Option<bool>)` 传 `None` 走自动判定（原图分 ≥20 **且** scale≈1.0）。附带：`.refinebox` 同时作为 stamp 逆解的第二个门控（`apply_stamp_inverse` 内部照旧用模板自定位，找不到就跳过）。
- **精分割残留要退化而不是报错**：精分割对**半透明软边**水印必然漏（顶帽看不出来），实测豆包 1/6.png 精分割后模板分仍有 20.5/31.2 ≥20。此时直接退化到用户**已声明**的整框重跑即可（`residual_retry` 见 `.refinebox` 就整框，否则照旧 5x5 膨胀），结果与"不用 refine"等价、`outside changed 0`，绝不因实验能力让用户拿不到结果。
- **FFT 不可导出 ONNX**（`aten::fft_rfftn` 不支持）；Carve 固定 512 正因 FFT 固定尺寸可预计算为矩阵乘。
